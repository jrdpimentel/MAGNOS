# Remote desktop and printing

## Remote desktop
Use a VNC tool such as **TightVNC** (free): install the server part on each customer PC with a password, and the Viewer on the admin PC. Connect to the IP shown on the dashboard's **Remote** page.
Windows Remote Desktop (.rdp) usually signs out the customer who is using the PC, so use it only on idle PCs.

## Printing
Share a printer from one PC (or a print server) and connect the customer PCs to it, or run a free FTP server such as **FileZilla Server** with a "Print" folder that staff pick up from.
This software does not include its own FTP or print server.
