# Roadmap

Status of planned work. Items marked "good first issue" are small and self-contained.

## Next
- [ ] **Per-user staff accounts** with roles and an audit log (today there is one shared admin key).
- [ ] **HTTPS out of the box** (self-signed certificate generated by the installer, or a built-in tunnel guide).
- [ ] **Entity Framework migrations** to replace the lightweight schema upgrader.
- [ ] **Split `Program.cs` on the server** into one file per feature (sessions, shop, chat, portal).
- [ ] **Client tests**: extract the lock-down and session-widget logic behind interfaces so they can be unit tested.

## Later
- [ ] Customer ordering from the PC ("Shop" button), with staff approval.
- [ ] Reports export (CSV / PDF) and end-of-shift summary.
- [ ] Multi-branch support and cloud sync.
- [ ] Game and application launcher per tier, with licence tracking.
- [ ] Installer wizard (MSI) with code signing.
- [ ] Localisation (English / Filipino).
